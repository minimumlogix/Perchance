How to Use & Import this Plugin

1. Standard Web Integration

Download both files using the exports. Put index.html and style.css in the same folder. Opening index.html will render the final styled results beautifully in any browser.

2. Perchance Hosting Setup

Import this plugin code into the Perchance lists using stylizer = {import:css-text-stylizer}. You can copy the stylesheet rules directly into your Perchance custom CSS panel or bind inputs programmatically.
